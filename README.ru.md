## Возможности

### Основной калькулятор (в стиле Casio)
- **Программируемая клавиатура в стиле Casio** -- ввод только с помощью экранных клавиш, исключает неоднозначность кодировки символов
- Полное вычисление выражений с учётом приоритета операторов и скобок
- **Система модификаторов SHIFT / ALPHA** для вторичных функций
- **Память**: M+ / M- / STO / RCL (переменные A-F, X, Y, M)
- **Режимы углов**: Градусы / Радианы / Грады (циклическое переключение DRG)
- **5 режимов вывода**: Обычный / Научный / Инженерный / Дробный / Линейный (переключение через NORM/SCI/ENG)
- Тригонометрия: sin / cos / tan + обратные; гиперболические: sinh / cosh / tanh + обратные
- Степени и корни: `x^2`, `x^3`, `^`, `sqrt`, `cbrt`, `1/x`, `|x|`
- Логарифмы: `log` (по основанию 10) / `ln` (натуральный) + обратные `10^x` / `e^x`
- Константы: pi, e (число Эйлера)
- Комбинаторика: факториал `x!`, случайные числа
- **История вычислений** с повторным вызовом + поиском + повторным использованием в один клик
- **Панель конвертации единиц измерения**

### Переменная клавиатура (Неизвестные)
- Выделенная кнопка **VAR** на основной клавиатуре открывает всплывающую панель переменных
- **Строчные буквы**: a-z + pi (28 клавиш)
- **Прописные буквы**: A-Z + theta + lambda (28 клавиш)
- **Греческие буквы**: alpha, beta, gamma, delta, epsilon, mu, sigma, omega, phi, psi, eta, rho, tau, infinity (14 клавиш)
- Поддерживаются все однобуквенные переменные (A-Z, a-z) в вычислительном ядре
- Панель глобального связывания параметров для построения графиков (a, b, c, m, n, k, d, z)

### Построение графиков функций + Рисование + Геометрические построения

**Построитель нескольких функций**
- Одновременное построение **16** функций (палитра из 16 цветов -- без повторения цветов для многих функций)
- Панорамирование в реальном времени (перетаскивание) и масштабирование (колесо мыши)
- Адаптивная координатная сетка с автоматической подписью
- Полноэкранный режим со сворачиваемой панелью управления функциями (кнопка **Menu** в левом верхнем углу, закрытие через переключатель меню / кнопку X / клик по фону)
- **Параметрические уравнения**: x(t) и y(t) с настраиваемым диапазоном t
- **Подсветка выбранной функции**: строка выбранной функции отображает значок + выделение границы; кривая на холсте использует двойной штрих (внешнее свечение + внутреннее жирное начертание)

**Рисование от руки (режим эскиза)**
- Свободное рисование или письмо на холсте графика
- Палитра из 8 цветов (Синий / Розовый / Изумрудный / Янтарный / Фиолетовый / Голубой / Розовый / Белый)
- Настраиваемая толщина штриха (1-8 px)
- Штрихи хранятся в **математических координатах** -- они перемещаются и масштабируются вместе с сеткой
- Очистка в один клик

**Инструменты геометрических построений**

| Инструмент | Описание |
|------|-------------|
| **Точка** | Клик в любом месте размещает подписанную точку (P1, P2...) |
| **Прямая** | Два клика -- рисует бесконечную прямую (простирается до краёв экрана) |
| **Отрезок** | Два клика -- рисует конечный отрезок (с маркерами концов) |
| **Параллельная** | 1. Клик рядом с прямой/отрезком 2. Клик по точке -- параллельная прямая через эту точку |
| **Перпендикуляр** | 1. Клик рядом с прямой/отрезком 2. Клик по точке -- перпендикулярная прямая через эту точку |
| **Пересечение** | 1. Клик рядом с функцией A 2. Клик рядом с функцией B -- находит пересечение с помощью сканирования по 500 точкам + 50-кратной бисекции (точность ~1e-15), показывает точку + координаты |

Выбранные опорные линии (параллельные/перпендикулярные) подсвечиваются более ярким цветом, жирным штрихом и эффектом свечения.

### Расширенная математика (5 выделенных вкладок)

| Вкладка | Возможности |
|-----|-------------|
| **Уравнения (EQN)** | Решение квадратных уравнений (ax^2+bx+c=0, включая комплексные корни); решение кубических уравнений (формула Кардано); поиск корней любой функции одной переменной (бисекция + Ньютон); линейные системы nxn (метод Гаусса с частичным выбором ведущего элемента) |
| **Матрицы (MAT)** | Матрицы A/B/C + арифметика -- сложение, вычитание, умножение, транспонирование, определитель, обратная матрица, ранг, ступенчатый вид |
| **Векторы (VEC)** | Векторы a/b -- сложение, вычитание, скалярное произведение, векторное произведение, норма, нормирование, угол между векторами, скалярная/векторная проекция |
| **Статистика (STAT)** | Ввод X + необязательные данные Y -> среднее, медиана, мода, мин/макс, Q1/Q3, дисперсия, стандартное отклонение, ковариация, коэффициент корреляции Пирсона (r), линейная регрессия y = a + bx |
| **Матанализ (MOD)** | Численное дифференцирование (1-го и 2-го порядка, центральная разность 4-го порядка); адаптивное численное интегрирование (Симпсон 1/3) |

### Интеграция Python и математических скриптов

Три режима выполнения в одной панели:

| Режим | Описание |
|------|-------------|
| **Math Script** | Лёгкий интерпретатор с нулевой загрузкой и мгновенным запуском. Поддерживает: присваивание переменных, `print()`, `for x in range(a,b,c)`, `if`/`elif`/`else`, определение функций `def`, все научные функции (sin, cos, tan, log, ln, sqrt, abs, floor...) |
| **Native Python** | Вызывает локально установленный интерпретатор Python через Electron IPC. Поддерживает стандартную библиотеку + сторонние пакеты. Требуется Python 3 в PATH. |
| **Pyodide** | Python на WebAssembly в браузере -- установка не требуется. Работает в песочнице со стандартной библиотекой и numpy. |

**Защитные механизмы** (во всех трёх режимах):
- Предварительное сканирование: отклоняет гигантские показатели степени вида `**100000`, `range(100000000)`, `[x]*100000000`, `"x"*100000000`
- **15-секундный тайм-аут** Pyodide (Promise.race)
- **Обрезка вывода** stdout/stderr Pyodide до **200 КБ**
- Math Script: **ограничение в 500 000 операторов** + **ограничение в 10 000 строк вывода** (защита от бесконечных циклов)
- Вычислительное ядро: предварительная проверка переполнения показателя степени (`|b| > 300 && |a| > 1`)
- Native Python: **буфер stdout/stderr объёмом 5 МБ** + тайм-аут процесса

### UI / UX

- **Дизайн Glassmorphism (матовое стекло)** с многослойным `backdrop-blur` + фоновым градиентом aurora
- **Три режима темы** (на основе CSS-переменных, динамическое переключение):
  - **Следовать системе** -- соответствует теме ОС
  - **Тёмная** -- глубокий космос, полностью протестирована
  - **Светлая** -- чистый белый, полностью протестирована (без невидимого текста)
- Анимированный фон aurora и пульсация логотипа (только SVG-иконки -- никаких эмодзи)
- **Подсказки при наведении** -- наведение курсора на любую клавишу показывает подробное описание её функции в левой нижней панели
- **Интерфейс на 7 языках** с раскрывающимся списком Language в верхней панели (иконка SVG в виде глобуса):
  - Упрощённый китайский (zhongwen)
  - Традиционный китайский (fantizi)
  - Английский
  - Японский (nihongo)
  - Русский (russkiy)
  - Французский (francais)
  - Немецкий (deutsch)
- **Адаптивный макет**: альбомная ориентация (клавиши слева, экран справа) на десктопе; портретная ориентация (экран сверху, клавиатура снизу) на мобильных устройствах с динамическим масштабированием для сверхузких экранов 380px и сверхнизких экранов 520px

### Десктоп и мобильные устройства

- **Windows**: установщик NSIS + портативный EXE + ZIP-архив
- **Android**: интеграция Capacitor 6, готовность к сборке APK (debug + release)

## Начало работы

### Предварительные требования
- **Node.js >= 18** (рекомендуется: 20 LTS)
- **npm**

### Установка зависимостей
```bash
npm install
```

### Разработка
```bash
# Веб-сервер разработки (http://localhost:5173)
npm run dev

# Режим десктопной разработки Electron (окно приложения)
npm run electron:dev
```

### Сборка десктопной версии (Windows EXE)
```bash
# Сборка фронтенд-ассетов (dist/)
npm run build

# Windows: установщик NSIS + портативный EXE + ZIP
npm run electron:build:win
```

Артефакты сборки выводятся в `release-scp-v1.2.1b/`.

### Сборка Android (APK)

**Сборка в один клик (рекомендуется):**
```bash
# Отладочный APK (двойной клик или командная строка)
build-apk.bat debug

# Release-APK
build-apk.bat release
```

**Сначала проверка среды:**
```bash
scripts\android-envcheck.bat
```

Скрипт сборки автоматически определяет JDK (приоритет: Android Studio JBR 21 -> JAVA_HOME -> Adoptium/Microsoft JDK -> PATH) и Android SDK (ANDROID_HOME -> ANDROID_SDK_ROOT -> %LOCALAPPDATA%\Android\Sdk). Он отклоняет JDK 22 (несовместим с Gradle 8.7).

Артефакты сборки выводятся в `release-android/`.
