Профессиональный научный калькулятор для десктопа с клавиатурой в стиле Casio, стеклянным UI (glassmorphism), поддержкой нескольких тем и продвинутой математикой.

Разработано **Prism Technology Studio** (c) 2026

## Возможности

### Основной калькулятор
- Ввод с софт-клавиатуры в стиле Casio (физическая клавиатура не требуется, исключает неоднозначность кодировок)
- Стандартные арифметические действия с полноценным вычислением выражений
- Режимы углов: градусы / радианы / грады
- Форматы записи: обычный / фиксированный / научный / инженерный
- История вычислений с возвратом значений
- Панель конвертации единиц измерения

### Построение графиков
- Одновременная отрисовка нескольких функций
- Палитра из 16 цветов для различения кривых
- Перетаскивание мышью/сенсором и зум колесом
- Адаптивная координатная сетка
- Полноэкранный режим: кнопка «Меню» в левом верхнем углу выдвигает панель управления функциями сверху

### Продвинутая математика
- **Уравнения**: квадратные, кубические, системы линейных уравнений, нелинейные уравнения
- **Матрицы**: сложение, вычитание, умножение, транспонирование, определитель, обратная матрица, ранг
- **Векторы**: сложение, вычитание, скалярное и векторное произведение, норма, нормализация, угол, проекция
- **Статистика**: среднее, медиана, дисперсия, стандартное отклонение, квартили, корреляция, линейная регрессия
- **Математический анализ**: численное дифференцирование и определённый интеграл

### Интеграция с Python
- **Математический скрипт**: встроенный лёгкий интерпретатор (переменные, функции, циклы for-range, if-else)
- **Системный Python**: вызов локального Python через Electron IPC (если установлен)
- **Pyodide**: Python в браузере на WebAssembly (установка не требуется)

### Интерфейс (UI / UX)
- Дизайн в стиле glassmorphism (матовое стекло, backdrop blur)
- Три темы: Системная / Тёмная / Светлая (на основе CSS-переменных)
- Анимированный аврора-фон и пульсация логотипа
- Подсказки при наведении: наведите курсор на любую клавишу, чтобы увидеть её назначение
- Многоязычность (7 языков), переключатель Language в верхней панели
- Адаптивная вёрстка: на десктопе — горизонтальная раскладка (клавиатура слева, дисплей справа)

### Десктоп и мобильные платформы
- **Windows**: инсталлятор NSIS, портативный EXE, ZIP-архив
- **Android**: интеграция через Capacitor (сборка APK готова)

## Структура проекта

```
src/
  components/       # Vue-компоненты UI
    CalcScreen.vue       # Дисплей калькулятора
    CalcKeyboard.vue     # Раскладка софт-клавиатуры
    CalcKey.vue           # Отдельная клавиша
    GraphPanel.vue        # Построитель графиков
    AdvancedPanel.vue     # Уравнения/Матрицы/Векторы/Статистика/Анализ
    PythonPanel.vue       # Python / редактор скриптов
    SettingsPanel.vue     # Конвертер единиц и настройки
    HistoryPanel.vue      # История вычислений
  composables/     # Vue composable-функции
    useCalculator.ts      # Состояние ядра калькулятора
    useInputRouter.ts     # Маршрутизация ввода с софт-клавиатуры
    useHoverHint.ts       # Общее состояние подсказок при наведении
    useTheme.ts           # Управление темами
  engine/          # Ядро математических вычислений
    calculator.ts         # Парсер и вычислитель выражений
    advanced.ts           # Продвинутые математические операции
    script.ts             # Интерпретатор математического скрипта
  i18n/            # Интернационализация
    messages.ts           # Переводы: zh-CN / zh-TW / en-US / ja-JP / ru-RU / fr-FR / de-DE
    index.ts              # Composable для перевода + реестр языков
  constants/       # Описания раскладок клавиш
  types/            # Определения типов TypeScript
electron/
  main.js           # Основной процесс Electron
  preload.js        # preload-мост API
scripts/
  gen-icons.js      # Генерация иконок (PNG / ICO)
```

## Быстрый старт

### Требования

- Node.js >= 18
- npm или yarn

### Установка

```bash
npm install
```

### Разработка

```bash
# Web-сервер для разработки
npm run dev

# Разработка под Electron
npm run electron:dev
```

### Сборка

```bash
# Windows: инсталлятор + портативная версия + ZIP
npm run electron:build:win

# Сгенерировать иконки
npm run icons

# Android APK (требуется Android SDK)
npm run android:apk
```

Артефакты сборки помещаются в каталог `release-final/`.
